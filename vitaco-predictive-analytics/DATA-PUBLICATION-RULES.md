# Conservative data publication rules

This project follows a strict publication boundary.

## Rule

**Do not publish any dataset, raw data file, extracted dataset, cleaned dataset, generated copy, row-level output, or redistribution of third-party data unless its licence explicitly permits redistribution/public sharing and we have verified that permission.**

Public availability is not treated as a licence.

## Applied to this project

- No raw source datasets are stored in the repository.
- No cleaned copies of source datasets are stored in the repository.
- No row-level predictions or extracted records are stored in the repository.
- No assessment appendices or working files are stored in the repository.
- The Demand & Supply Planning source was treated conservatively because its Kaggle listing was identified as **Other (specified in description)** and redistribution rights were not established.
- The Machine Downtime Analysis source was identified as Apache 2.0, but the portfolio does not redistribute it because publishing the raw data is unnecessary to demonstrate the analytical capability.

## Reproducibility approach

Where public reproducibility is needed, the preferred approach is to create a **fully synthetic demonstration dataset** that contains no copied source records and is clearly labelled synthetic. The synthetic data should reproduce the analytical structure, not the original records.

## What is safe to show here

This repository may show:

- analytical reasoning;
- model-selection rationale;
- methodology;
- evaluation metrics derived from the academic analysis;
- limitations and validation considerations;
- original explanatory text;
- independently written demonstration code; and
- synthetic demonstration data created specifically for the portfolio.

This file is a project-level publication control, not legal advice. Where a licence or permission is unclear, the conservative decision is **do not publish the data**.
