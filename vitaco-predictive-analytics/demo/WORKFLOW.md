# Reproducible synthetic workflow

This demonstration is deliberately separate from the original academic data.

## Pipeline

**Synthetic data → feature/target selection → train/test split → Decision Tree → predictions → confusion matrix → accuracy + failure recall → operational interpretation**

## Why this exists

The public portfolio should demonstrate analytical competence without publishing third-party or assessment data.

The synthetic dataset is independently generated and is **not Vitaco data**. It does not reproduce the original academic dataset.

## Conservative publication boundary

No original source rows, values, extracts, cleaned copies, or row-level academic outputs are used in this demonstration.

The original academic case study reported a Decision Tree accuracy of 92.52% and approximately 86.5% failure recall, but those figures belong to the academic analysis. They are not claimed as the performance of this synthetic demonstration.

The script in this folder produces its own metrics from the synthetic dataset.
