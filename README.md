# Data Analytics Portfolio

**Data analysis · research · predictive modelling · business intelligence**

This portfolio presents selected analytical work focused on turning business questions into structured analysis, evaluated models, and decision-support outputs.

## Featured project

### Vitaco Health Group — Predictive Analytics & Business Intelligence

A decision-oriented analytics case covering three connected problems:

- **Production-risk visibility** — Decision Tree classification and failure-recall analysis
- **Demand anticipation** — Python Random Forest modelling, baseline comparison and feature-importance analysis
- **Resource prioritisation** — multi-indicator allocation-pressure analysis

**Core workflow:**

> Business requirement → data role → analytical technique → evaluation → limitation → decision boundary

The project emphasises analytical judgement as much as modelling: interpreting errors, checking leakage risk, distinguishing prediction from causality, and identifying where human review remains necessary.

**Methods & tools:** Python · pandas · NumPy · scikit-learn · RapidMiner · Power BI · Excel

## Publication boundary

The repository does **not** publish university assessment submissions, transcripts, rubrics, lecturer feedback, raw or cleaned third-party datasets, extracted source data, or row-level academic outputs.

The Vitaco demonstration code uses **independently generated synthetic data**. It is not Vitaco internal data and is not copied, sampled, transformed, extracted, or derived from the academic source datasets. Generated CSV files are recreated locally and are not committed to the repository.

Dataset availability on a public platform is not treated as permission to redistribute data. Dataset licensing is verified before any source dataset is considered for publication.
